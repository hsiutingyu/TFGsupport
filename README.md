# TFGsupport

TFG 挺巧慧方形應援圖製作頁。

## 使用

- 可輸入或清空級別數字。
- 可選「同學、學姊、學妹、朋友、同鄉」，或自填兩個字。
- 可下載 3600 × 3600 像素的 PNG 和 JPEG。
- 所有圖像都在訪客的瀏覽器內製作，不需伺服器或外部字體。

## GitHub Pages

此資料夾可作為獨立的 `TFGsupport` 儲存庫。將 GitHub Pages 設為從 `main` 分支根目錄發布後，首頁位址為：

https://hsiutingyu.github.io/TFGsupport/

`TFGsupport.html` 也能透過 `/TFGsupport/TFGsupport.html` 開啟。獨立儲存庫無法直接提供主站根目錄的 `/TFGsupport.html`；如需該網址，需在主站儲存庫新增檔案或轉址。
